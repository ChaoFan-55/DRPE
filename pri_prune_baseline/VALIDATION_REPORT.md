# 交付前验证记录

本记录说明软件验证情况，不是正式实验结果。

- 在旧工程实际使用的PTF-FSR环境中核对：Python3.10、torch1.13.1+cu116、torchvision0.14.1+cu116；GPU为RTX3050Ti Laptop。
- 三种子的客户端划分重建成功，并与已保存DRPE客户端样本数逐项一致；训练45000、验证5000、测试10000。
- 模型参数量为11,173,962。基础幅值掩码对应FP32值、int32索引及计数字段的单客户端上传上限为13,474,432字节，约为完整更新的30.1469%。完整自适应防御的上传量需由正式运行实测。
- 8项测试通过：ST掩码与梯度、梯度加权隐私目标、实际载荷字节、样本加权聚合、偏置与归一化的基础掩码、私有状态与服务器隔离、攻击支持集适配、完整汇总与检查点错配拒绝。
- 使用原CIFAR数据和原ResNet18+GroupNorm完成GPU短训练：2轮、每个被选客户端1个批次。它只证明训练流程能运行，没有证明收敛。
- DLG和iDLG均完成3步短攻击；saved-PNG AlexNet LPIPS路径验证通过。它们只证明攻击及指标管线能运行，没有证明防御效果。
- 正式三种子各200轮及新增120次2000步攻击没有运行。压缩包不包含伪造的正式结果、短训练检查点或原工程数据。
- 核对过的原配置、代码、目标清单和既有逐次结果文件，在测试前后SHA256一致。原工程未作代码或结果编辑。

所有短流程与测试文件保留在Codex工作目录，未写入旧实验目录。最终包只含源码、配置、运行脚本、方法说明与本验证记录。
